# :books: Personal book wishlist and reading tracker

**A simple browser-based personal library application with a built-in reading tracker**

---
### :point_right: Introduction

The application will allow users to add books with one of three reading statuses:
- Want to Read: wish to read, based on a recommendation 
- Finished: books I've already read
- Currently Reading

In the third case, the app aims to track daily reading progress. Users can track the reading pace over time. Daily reading progress will also be processed into monthly and yearly reading statistics.

### :computer: Planned technologies

* PostgreSQL
* Python
* Power BI
* Streamlit
